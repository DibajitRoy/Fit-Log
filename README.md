# FitLog — Workout Library

FitLog is a dark, no-nonsense gym companion built with Next.js. Pick a lift, lock it into today's plan, and watch the week's work add up.

## Live Link
https://fitlogworkout.vercel.app/

## GitHub Repo Link
https://github.com/DibajitRoy/Fit-Log

## Technologies Used
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- daisyUI
- react-toastify
- react-icons

## Features
- Browse a library of 12 workouts fetched from a live API
- View detailed instructions, key specs and stats for each workout
- Add workouts to today's plan with a 5-lift cap
- Save workouts for later and manage them from the My Plan page
- Mark workouts as done or remove them with instant toast feedback
- Sort your plan by duration, calories or rating
- Fully responsive design across mobile, tablet and desktop
- Data persists in localStorage so your plan survives a page reload
